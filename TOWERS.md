# Tower parity checklist

Generated by `python -I tools/assets/audit_behaviors.py --by-tower`: behaviour models each shop tower's
tiers use that our export never reads. Some are visual-only or handled under another name; each is
checked and either implemented or noted here. Order: shop order.

## Code-verified audit (one tower at a time)

A tower is verified only when every behaviour in every tier (`python -I tools/assets/dump_tower.py
--all <Tower>` writes the full model trees to research/dumps/towers/) matches the game's code, not
a hypothesis. Core systems every tower shares come first.

Core (checked against SimRecorder recordings of the real game, tools/mod; `compare_recording`
reports 0 differing frames for a Dart Monkey on Monkey Meadow, CHIMPS, rounds 1-3):
- [x] Weapon timing (Weapon.Process / CalcRateFrames / UpdateMissedFrames / SpawnDart /
  ApplyStartingCooldown): whole frames, round clock, throw delay, missed-frame shots, state kept
  through upgrades.
- [x] CritMultiplier.
- [x] Bloon spawn and leak (Path.InitEntryExits spawnDist / leakDist, Bloon.Move / Process).
- [x] Emission timing (BloonGroupModel.GetEmissions, Spawner.Process elapsed).
- [x] Bloon position (Path.DistanceToPointInfoBloon: 4 off the path line).
- [x] Frame order: collisions first (frame-start positions), then towers, then bloons move, then
  projectiles; new bloons and projectiles wait a frame; children start where the parent was.
- [x] Targeting range: in-range PathSegments (segment point within range, bloon on segment
  (int)(distance / 7)).
- [x] Aim and throw point (RotateToTarget.ApplyRotation from 10 above the tower,
  Weapon.GetEjectPosition with AddDisplaySpaceHeight; y flipped in the clone).
- [x] Line of sight: Map.IsTargetLineClear (blocker areas taller than the tower; segment point
  for ordinary bloons). It, not "segment on the map", is what keeps off-screen bloons untargeted.
- [x] MOAB targeting: segments within range + 40, Targetting.CanHitMoab collision circles
  (CollisionGroupData, offset turned by the path's QuickPointInfo rotation), circle aim only when
  the bloon's own segment isn't in range + 2 with a clear line; the throw keeps the exact offset.
- [x] Projectile hits by layer: collidedWith holds Bloon.layerId, lineage the layers it came from.
- [x] Knockback (Collide / KnockbackMutator / IsBloonValidForPushback), children included.
- [x] ExpireProjectileAtScreenEdge after the move, MapBorderRebound (crossing from on-map only),
  TravelStrait's last frame (no move), ArcEmission angles (rotation - angle/2 + offset + k slice,
  from the emitting tower's rotation), exhaust children move the next frame.
- [x] Pop children: no entrance clamp until their first move; path list entries in nested pops.
- [x] Spawner emits after the frame's collisions (ids / list order).
- [x] Close mode (Attack.CompareBracketClose + List.Sort emulated exactly). [ ] PrioCamo.
- [ ] Damage, immunity and pop/children beyond Red/Blue (more recordings).
- [ ] The game's RNG and the order it is drawn in.
- [ ] Monkey Knowledge (the real game applies it; scenarios use CHIMPS to turn it off).
- [x] A throw whose target is gone (Target.IsValid) leaves along the tower's current facing.
- [x] Frame order: collisions before towers (Simulation.Simulate process list), projectile
  movement / exhaust after; MOAB rotation lerp (UpdatePositionAlongTrack); MOAB hits only through
  its collision circles; collision grid filled in pre-flush order; Weapon.RoundStart;
  ApplyExtraDamagePrecision; MonkeyFanClub selection and Mutator.
