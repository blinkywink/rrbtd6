Getting started

  1. Prepare BTD6

    Install MelonLoader 0.7.3 in your Windows copy of BTD6, then run the game once.

  2. Add the installer

    Download RRBTD6Installer.dll and put it in BTD6's Mods folder.

  3. Launch BTD6

    Choose where to install RustTD6. The launcher downloads the client and tools, then prepares assets from your game. Completed steps can resume.

First setupVaries by PC

The download is small; preparing local game assets is the large part. We are measuring clean-install size and time. Assets stay on your PC, and setup shows progress.

Why is it bigger than BTD6?

BTD6 stores compressed assets. This prototype currently expands animations and audio into larger files for its own engine. That storage overhead needs more work. Temporary bundle caches are removed after successful setup.

Python and extraction tools download during setup.
