What's different

  • Increased performance
    Late-game rounds stay smooth where BTD6 slows to a crawl, with about 5× the average FPS.
  • More graphics settings
    Render scale, sharpening, anti-aliasing, VSync and an FPS limit.
  • A tidier main menu
    Hide the buttons you never use and skip straight past the startup screens.
  • Plays like the real thing
    Each tower is recorded in BTD6 and compared frame by frame until RustTD6 matches it exactly.
  • Everything unlocked
    Every tower, upgrade and hero is available from the start. Monkey XP still counts up, so you can see which towers you use most.
  • Private co-op
    Play with friends over an encrypted peer-to-peer room. The host can even share their mods with everyone in it.

Install in three steps

  1. 1 Install MelonLoader 0.7.3 into BTD6 and launch the game once.
  2. 2 Put the downloaded RRBTD6Installer.dll in BTD6's Mods folder.
  3. 3 Open BTD6 and choose a folder for RustTD6. The launcher sets up the rest, and keeps RustTD6 up to date from then on.

The first setup prepares your game's assets and can take a while. Keep BTD6 open: a progress window shows the current stage and the estimated time left. It uses a lot of memory, so closing other programs speeds it up.

Make it yours

Write mods as plain files: new towers, projectiles, bloons, modes, shop layouts, upgrades and custom models. Add event scripts with their own in-match UI. Reload them from the Mods menu without restarting the client.

Read the Mod API docs → 
# mods/quickstart/mod.py
mod = Mod("quickstart", "Quick Start")

dart = mod.tower("dart", base="DartMonkey", cost=100)
dart.projectile(damage=3, pierce=4)
dart.weapon(rate=0.5)

mod.mode("training", base="Medium", cash=2000)

Platforms

Installer Windows

Download the installer above. The launcher installs and updates everything.

Build it yourself macOS

Copy your game data from a Windows install, then run tools/build_macos.sh to build RustTD6.app. Apple Silicon.

Build it yourself Linux

Copy your game data from a Windows install, then run tools/build_linux.sh. Needs the X11, OpenGL and ALSA development packages.

macOS and Linux builds are for personal use and aren't distributed. Instructions are in the README.

FAQ

Do I need to own BTD6?

Yes. RustTD6 doesn't include the game. It's built from the files in your own copy.

Is it finished?

No, it's early. Towers are being matched to the real game one at a time, and some modes and features aren't in yet. Progress is tracked on GitHub.

Does it change my BTD6 save or account?

No. RustTD6 keeps its own local progress. The installer and launcher only contact GitHub, python.org and PyPI; they never contact Ninja Kiwi and never change BTD6, your save or your account.

Can I play it on a Mac or Linux?

Yes, with a personal build. Set it up on Windows first, copy the extracted game data across, and run the build script for your system. See Platforms.

Is it safe?

The code is open source, so anyone can read exactly what it does. It's still unofficial software, so use it at your own discretion.

Does it cost anything?

No. It's free. If you want to support Ninja Kiwi, buy things through the official game or their webstore.

Is this from Ninja Kiwi?

No. It's an unofficial fan project, not affiliated with or endorsed by Ninja Kiwi.
