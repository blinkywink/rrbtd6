A fan-made Rust client for co-op, mods and late-game experiments. Bring your own copy of BTD6, with everything unlocked and no account required.

Download for Windows

What's different

  • No frame cap Play at your monitor's full refresh rate, or set your own limit.
  • More graphics settings Render scale, sharpening, anti-aliasing, VSync and an FPS limit.
  • A tidier main menu Hide the buttons you never use and skip straight past the startup screens.
  • Plays like the real thing Each tower is recorded in BTD6 and compared frame by frame until RustTD6 matches it exactly.
  • Built-in mods Enable local mods from the main menu. Rebuild a mod and start a new match without restarting the client.
  • Code your own changes Towers, models, projectiles, modes, shop layouts and scripted in-match UI. Explore the API.

Install

  1. 1 Install MelonLoader 0.7.3 into BTD6 and launch the game once.
  2. 2 Put the downloaded RRBTD6Installer.dll in BTD6's Mods folder.
  3. 3 Open BTD6 and choose a folder for RustTD6. The launcher sets up the rest.

The first setup copies art and sound from your game, so it takes a little while.

How it works

RustTD6 isn't a mod that changes BTD6. It's a separate program. The installer reads the art, sounds and tower stats from your BTD6 install, and RustTD6 runs them on its own engine. None of Ninja Kiwi's files are hosted or shared, which is why you need to own the game.

FAQ

Do I need to own BTD6?

Yes. RustTD6 doesn't include the game. It's built from the files in your own copy.

Is it finished?

No, it's early. Towers are being matched to the real game one at a time, and some modes and features aren't in yet. Progress is tracked on GitHub.

Is it safe?

The code is open source, so anyone can read exactly what it does. It's still unofficial software, so use it at your own discretion.

Does it cost anything?

No. It's free.

Is this from Ninja Kiwi?

No. It's an unofficial fan project, not affiliated with or endorsed by Ninja Kiwi.
