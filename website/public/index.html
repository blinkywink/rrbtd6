Windows · Requires your own copy of BTD6

How to install +
  1. Install MelonLoader 0.7.3 in BTD6. Run it once.
  2. Put the downloaded RRBTD6Installer.dll in BTD6's Mods folder.
  3. Open BTD6 and choose an install folder. The launcher handles the rest.

First setup prepares assets from your game. Time and storage vary; clean-install measurements are pending.
