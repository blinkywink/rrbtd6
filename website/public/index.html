A SMALL CLIENT. A BIG FIRST SETUP.

Bring your game.
We'll bring the engine.

RustTD6 doesn't ship any BTD6 art, audio, or game data. The launcher prepares those assets locally from your installed copy. That's why the first setup takes a while—and why the download is much smaller than the finished install.

FIRST SETUPSet aside an hour or more*
  1. 01

    Get BTD6 ready.

    Install Bloons TD 6 on Windows, then install MelonLoader 0.7.3 ↗ into that game. Start BTD6 once so MelonLoader can finish preparing.

  2. 02

    Drop in the installer.

    Download RRBTD6Installer.dll using the button here. Put it in the Mods folder inside your BTD6 installation. It's a mod file, so you don't open it by double-clicking.

  3. 03

    Open BTD6. Pick a home.

    At the main menu, the installer offers to set up RustTD6. Choose an install folder with enough free space. The launcher downloads the client and its extraction tools.

  4. 04

    Let the launcher do its thing.

    It sets up a private Python runtime and prepares assets from your installed game. This is the long part. Completed extraction steps are remembered if setup is interrupted.

    ↳ Next time, use the RustTD6 launcher. It checks for updates and reuses finished assets.

* Planning estimates, not benchmark results. Time and disk use depend on your CPU, drive, connection, and BTD6 version. Some PCs will take several hours. The space allowance excludes BTD6 itself and includes temporary extraction files. An official game update can require assets to be prepared again.

Still curious?
The project lives on GitHub ↗

Is this official?+

No. RustTD6 is an independent, fan-made project. It is not affiliated with, endorsed by, or sponsored by Ninja Kiwi. Bloons TD 6 and its original assets belong to their respective owners.

Do I need to own Bloons TD 6?+

Yes. You need a legitimately owned, installed Windows PC copy of BTD6. RustTD6 contains the client and tools, not the original game's artwork, audio, maps, or other proprietary data. Please support the original game.

Is everything finished?+

No. This is an experimental client in active development. Faithful gameplay is the aim, but some mechanics, menus, account features, and co-op behavior are incomplete. The feature descriptions here aren't a promise of complete parity or a specific FPS gain.

Why is the first setup so big?+

Preparing the game locally creates models, baked animations, textures, and decoded audio in formats this engine can use. Temporary bundle caches also add to peak space usage. The downloaded client is only a small part of that total. Setup improvements are ongoing.

Will I need to do all that every time?+

Normally, no. The launcher remembers completed extraction steps and keeps local assets across client updates. Changed exporters or an official BTD6 update may require some or all assets to be prepared again.

Can I use my usual mods or official co-op?+

Don't assume compatibility. RustTD6 is a separate engine, so existing BTD6 mods are not automatically supported. Expanded mod tooling is planned. Co-op is under development; compatibility with official BTD6 clients is not available.
