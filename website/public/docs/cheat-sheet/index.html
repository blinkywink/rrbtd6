Reference

Cheat sheet

Every SDK call, script hook and command on one page.

Mod

CallDoes
Mod(id, name, version="1.0.0", description="")Starts the mod. IDs are lowercase letters, digits, ., _ and -.
mod.tower(name, base="DartMonkey", **stats)Clones a tower; returns a tower handle
mod.existing_tower(id)A handle on a game tower, without cloning it
mod.bloon(name, base="Red", **fields)Clones a bloon
mod.mode(name, base="Medium", **fields)Adds a custom mode
mod.all_modes(**fields)Changes every mode
mod.projectile(name, base_tower=, base_tier=, **fields)A projectile template to give towers
mod.script(name, source | file=, tick_interval=60)Embeds an event script
mod.menu(page, path, text=, visible=)Changes a menu node's text or visibility
mod.set / insert / remove / copyRaw edits by JSON Pointer path

Tower handle

CallDoes
.stats(**fields)Sets tower fields such as cost or range
.weapon(tier="000", attack=0, weapon=0, **fields)Sets weapon fields such as rate
.projectile(template=None, tier="000", **fields)Sets projectile fields such as damage, pierce
.upgrade(path, tier, cost=, stats=, weapon=, projectile=, model=)Edits an upgrade (paths 0–2, tiers 1–5)
.shop(before= | after= | index=, visible=, category=)Moves, hides or recategorises it in the shop
.model(asset, tiers=None)Uses a baked custom model

Script hooks

on_new_game, on_round_start, on_round_end, on_tower_placed, on_tower_sold, on_towers_changed, on_pop, on_tick, on_query. Details in Event scripts.

Script commands

CommandDoes
cashAdds cash (negative subtracts)
livesSets lives
spawnSends bloons
clear_bloonsRemoves every bloon
reset_cooldownsReadies every ability
popupShows a message
ui / remove_uiOpens or closes a custom panel
inspectAsks for live entity data
entity_patch / damage_bloonEdits a live tower, bloon or projectile
listenTurns a behaviour interceptor on or off

Build and reload

python tools/modsdk.py build mods/<id>/mod.py
# then in the client: Mods -> Reload Mods -> switch it on -> new game
