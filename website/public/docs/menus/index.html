Content API

Menus

Changing text and visibility of existing frontend nodes.

mod.menu("MainMenuUI", "<node path>", visible=False)  # path from your ui/prefabs/MainMenuUI.json
  • page matches an exported prefab filename, such as MainMenuUI.
  • path matches the node hierarchy in your local ui/prefabs export.
  • Set text or visible; use them separately.
  • The edit applies when that scene loads. Values the game updates dynamically may overwrite it.

For interactive in-match panels, use custom UI from an event script instead. Arbitrary new frontend screens aren't implemented yet.
