Getting started

Your first script

Step by step: a mod that pays a growing bonus after every round.

Content edits change the game's data. Scripts add behaviour that runs during a match. This tutorial builds a small script mod from an empty folder.

1. Make the folder

Create mods/round-bonus/ next to your game, with two files in it.

2. Write mod.py

mod = Mod("round-bonus", "Round Bonus", description="Extra cash every round.")
mod.script("bonus", file="bonus.rhai")

The mod has no content edits, just one script. file is read from the same folder when you build.

3. Write bonus.rhai

fn on_new_game(ctx) {
    this.bonus = 50;
    [#{op: "popup", title: "Round Bonus", body: "You get extra cash after every round."}]
}

fn on_round_end(ctx) {
    if ctx.sandbox { return []; }
    let paid = this.bonus;
    this.bonus += 25;
    [#{op: "cash", amount: paid}]
}
  • on_new_game runs once when the match starts. It stores the first bonus in this and shows a popup.
  • on_round_end runs after every round. It skips Sandbox, pays the bonus, and raises it by 25 for next time.
  • Each callback returns a list of commands. An empty list, [], means "do nothing".

4. Build and play

python tools/modsdk.py build mods/round-bonus/mod.py

Open Mods, press Reload Mods, switch on Round Bonus and start a new game. The popup appears, and your cash jumps after each round: 50, then 75, then 100.

Take it further

  • Scale with progress instead: [#{op: "cash", amount: 50 + ctx.round * 10}].
  • Send extra bloons at the start of each round with on_round_start and a spawn command.
  • Add a button and a panel with Custom UI.
Tip

If a callback errors or returns a bad command, that script is switched off for the rest of the match. See Troubleshooting.

Every hook, field and command is listed in Event scripts.
