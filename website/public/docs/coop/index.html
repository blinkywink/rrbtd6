Playing

Co-op

Sharing a mod set in a private room.

Host a private iroh room and open Room Mods. Only the host chooses the set; guests can inspect it.

  • The host sends hash-checked manifests over the encrypted peer-to-peer connection, even to players who don't have those mods installed.
  • Received manifests stay isolated in the room; they don't replace installed mods, and author scripts or native code are never sent or run.
  • Changing the set clears everyone's Ready state. Starting the match locks it.
  • The normal load barrier checks the compiled starting state.
  • All players need the same client build and base game data.
LimitValue
Data mods per room16
Manifest text24 KiB (40 KiB encoded)
Runtime script modsNot yet supported
Custom artNot yet supported (rejected with a message)

Official-server interoperability isn't implemented. Use a private RustTD6 room.
