Limits & roadmap

Every limit in one place, and what isn't implemented yet.

Limits

WhatLimit
Manifest size64 KiB
Operations per mod256
Installed mod folders256
Mod ID1–64 characters
Script source32 KiB
Operations per callback / per tick30,000 / 100,000
Commands per callback32
Persistent script state64 KiB
UI widgets / nodes / depth / bindings64 / 128 / 12 / 32
Entity query page128 items; 8 per step; 64 pending
Model60,000 vertices; 600 frames per clip; 128 MiB poses
Mod icon512 × 512 px, 1 MiB
Co-op room16 data mods, 24 KiB of manifests

Not implemented yet

  • Fourth (and further) upgrade paths
  • Arbitrary new frontend screens (in-match overlays and menu edits work)
  • Custom map registration and import
  • Arbitrary new native behaviour types and unrestricted engine writes
  • Script mods and custom art in co-op
  • New profile counters

Direction

The goal is a general mod platform: arbitrary upgrade graphs, complete per-upgrade behaviour and art, custom maps with scripted interactions, custom UI with actions, and validated co-op dependency and asset sharing, all through documented code APIs that reload safely, with no in-game editor and no per-frame Python or DLL injection.
