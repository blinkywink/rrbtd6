Reference

Modder FAQ

Quick answers about what the mod system is and isn't.

Do MelonLoader mods work?

No. RustTD6 is a separate engine with its own mod format; BTD6 MelonLoader mods don't run in it.

Does Python run while I play?

No. Python only builds your manifest. During play the client runs native data and, optionally, sandboxed Rhai scripts.

Do I have to use Python?

No. Any tool that writes a valid mod.json works.

Do I need to restart the game after changing a mod?

No. Rebuild, press Reload Mods, and start a new match.

Can I include art or sounds from BTD6?

No. Never bundle or redistribute extracted game content. Reuse the game's art by cloning (each player's own install supplies it), or ship your own original models.

Do mods affect official events?

No. Official events bypass local content mods.

Can friends use my mod?

Data mods, yes: the host's room sends them to every player. Script mods and custom art aren't supported in co-op yet.

Can a script read my files or go online?

No. Scripts have no filesystem, network or process APIs, and run under strict operation and memory limits.

Can I add a fourth upgrade path?

Not yet. The engine and upgrade screen store exactly three paths. See what isn't implemented yet.
