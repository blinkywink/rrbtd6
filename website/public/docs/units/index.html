Units & coordinates

Time, distance, angle and UI units used across the API.

QuantityUnit
Simulation time60 steps per simulated second; tick_interval and ctx.tick count steps
Weapon rateSeconds between shots
Projectile velocityWorld units per step
Projectile remainingSeconds
direction (before_fire)Radians
Entity positionNative world coordinates
ctx.roundCompleted rounds
Upgrade paths / tiersPaths 0–2, tiers 1–5 (tower.upgrade); tier strings like "100" in helpers
Spawn spacingSeconds between bloons
UI rects3840 × 2160 reference canvas, Y up
ModelsGame units; the starter robot is about 14 units tall

Model axes

SourceUpForwardOrigin
OBJ import+Y+ZFeet at the origin
Blender export+Z−YFeet at the origin

--muzzle X HEIGHT FORWARD is in the model's own units; --release is seconds into the Attack clip.

IDs

  • Content IDs are namespaced by your mod ID (the SDK adds the prefix).
  • Entity IDs are stable within a match and are not array positions. Bloons also have a layer ID that changes as layers pop.
  • Mode IDs are stable names, not indices.
