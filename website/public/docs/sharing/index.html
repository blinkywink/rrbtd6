Playing

Sharing a mod

Pack a mod so someone else can install it, and what never to include.

What to send

Zip your mod's folder. Only mod.json is needed; everything else is optional.

FileNeeded?
mod.jsonYes. The built manifest is the mod; scripts are embedded in it.
icon.pngOptional artwork for the Mods menu
assets/Only if the mod uses custom models
mod.py, .rhai filesOptional. Include them if you want others to edit and rebuild it.

Installing someone else's mod

  1. In RustTD6, open Mods and press Open Mods Folder.
  2. Unzip the mod so its folder, with mod.json inside, sits in mods/.
  3. Press Reload Mods, switch it on and start a new game.

Updates

Raise the version when you change a mod, for example Mod("round-bonus", "Round Bonus", version="1.1.0"), rebuild, and send the new folder. Players replace the old folder and press Reload Mods. Keep the same mod ID, or it installs as a separate mod.

Playing it together

To play a data mod with friends, the host doesn't need to send files at all: a private co-op room shares its mods with everyone who joins. Scripts and custom art can't be shared that way yet. See Co-op.

Limit

Never include files extracted from BTD6 (textures, models, sounds or data from your install), and never include DLLs. Mods are original work plus edits to the player's own copy of the game.
