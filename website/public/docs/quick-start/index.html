Getting started

Quick start

Build and load a mod that adds a tower, a bloon and a mode.

You need

  • An installed copy of RustTD6. The SDK ships with it at tools/modsdk.py.
  • Python 3.10 or newer (only for building; nothing runs in Python during play).

1. Write the mod

Save this as mods/quickstart/mod.py, next to your game. Download it.

# The SDK supplies Mod when it builds this script.
mod = Mod("quickstart", "Quick Start", description="A custom dart, bloon and mode.")

dart = mod.tower("dart", base="DartMonkey", cost=100)
dart.projectile(damage=3, pierce=4)
dart.weapon(rate=0.5)

mod.bloon("durable-red", base="Red", maxHealth=5)
mod.mode("training", base="Medium", cash=2000, lives=300)

2. Build its manifest

From the installation folder:

python tools/modsdk.py build mods/quickstart/mod.py

This writes mods/quickstart/mod.json. You can also generate the same JSON from another language.

3. Enable it

  1. Turn on Settings → Advanced → UI → Show Mods Button.
  2. Open Mods and press Reload Mods.
  3. Flip the switch beside Quick Start. Selecting its row only previews its properties and settings.

4. Play

Start a new local game. Your tower is in the shop, your bloon is in Sandbox, and the mode screen has a custom-mode selector with training.

Edit, rebuild, reload

Change the script, build again, then press Reload Mods. Changes apply to the next new or restarted game. A match already in progress keeps the definitions it started with.

Tip

Hiding the Mods button doesn't disable enabled mods. Enabling and selecting are separate: the switch controls whether a mod is active.
